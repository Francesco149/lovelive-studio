# Love Live Studio

Make anime pictures in the art style of *Love Live! Sunshine!!* on your own PC: your own characters, any body type,
any scene. Everything runs on your computer, and nothing is uploaded anywhere.

You don't need to know anything technical. Claude installs it, keeps it working and helps you get the pictures you
want.

## Getting started (about 10 minutes of your time, then Claude works for a while)

1. Install the **Claude** app for Windows from https://claude.ai/download and sign in. Claude Code comes with a paid plan.
2. Open the app, go to the **Code** tab and start a session in your **Documents** folder (or any folder you like).
3. Paste this message and press Enter:

   > Please download the Love Live Studio from **&lt;the link you were given&gt;** into this folder and set it up for me
   > by following its CLAUDE.md. I'm not technical, so please do everything for me and explain as you go.

   If you got the Studio as a zip file instead, unzip it, start the Code session **inside** the unzipped folder and say:
   *"Please set this up for me by following CLAUDE.md."*
4. Claude checks your PC, **asks you which drive to use** (it needs about 25 GB), downloads everything and makes a test
   picture. Windows may ask for permission once (to install a Microsoft runtime): click **Yes**.

When it's done you'll have a **Love Live Studio** icon on your desktop.

## Making pictures

Double-click **Love Live Studio**. A page opens in your browser:

- Pick a **ready-made prompt**, change the character or scene in plain tags, pick a **body type** from the little
  drawings, and press **Make pictures**.
- Click a picture to rate it (❤️ 👍 😐 👎), leave a note, keep its settings or make variations.
- **Guide** explains how it works, how to write prompts, how to change body types and how to avoid the "generic AI
  face". It has lots of examples.

## Asking Claude for help

Open Claude, start a Code session **in the Studio's folder** (the one with this file), and just say what you want,
even vaguely:

- "Make her look less generic."
- "I want a chubby girl in a summer festival, like the examples but cuter."
- "Can we make a style that's more my own?"
- "The page doesn't open." / "Pictures come out black." / "My disk is full."

For bigger questions, Claude makes a small **round** of test pictures. You judge them in the Studio's *Rounds to judge*
tab, and Claude writes down what worked in your recipe book (the `my` folder) for next time.

## About the pictures

Anime models learned from a huge collection of internet pictures. Now and then a picture can come out more revealing
than you asked for. That's normal, it stays on your PC, and you can just ignore it, or tell Claude if you'd like it to
steer away from that.
